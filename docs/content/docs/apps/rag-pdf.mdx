  The `apps/rag-pdf` app is planned. It will provide RAG over PDF documents: chunking, embeddings, and semantic search similar to [RAG YouTube](/docs/apps/rag-youtube).
</Callout>

## Planned Scope

- PDF ingestion and text extraction
- Chunking and embedding pipeline
- Vector search (PGVector) and agent-based Q&A
- Reuse of patterns from `apps/rag-youtube` (embeddings, vector store, agent)
